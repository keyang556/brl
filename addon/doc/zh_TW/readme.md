# 中日韓點字增強

這個 NVDA 附加元件改善中文等連續書寫文字的點字輸出，
實作了以下 NVDA issue 所提出的功能：

* [#18295：為連續書寫語言重新定義文字換行行為](https://github.com/nvaccess/nvda/issues/18295)，包含留言中提出的各種行為。
* [#20726：在中文點字輸出中，可選擇在中文字、拉丁字母與數字之間插入空格](https://github.com/nvaccess/nvda/issues/20726)。

需要 NVDA 2026.3 或更新版本。

## 設定

設定位於 NVDA 設定對話框 (NVDA 功能表、偏好、設定) 的「中日韓點字」類別中，
並會儲存在目前的組態設定檔中。

### 中日韓字元的文字換行

中文的詞與詞之間沒有空格，而每個中文字都會轉譯成數個點字方。
使用 NVDA 的「在字詞邊界」文字換行時，一長串中文會整段移到下一個視窗，經常留下 20 方以上的空白。
關閉文字換行時，一個字可能會被拆開，前幾方在一個視窗的結尾，其餘在下一個視窗的開頭。

這個設定決定當點字顯示器的一列結束在中日韓文字 (漢字、注音符號、假名、中日韓標點符號與全形字元) 之中時的處理方式。
其他文字 (例如英文單字) 仍依照 NVDA 點字類別中的「文字換行」設定。

| 選項 | 行為 |
|---|---|
| 與 NVDA 文字換行相同 (預設) | 不改變 NVDA 的行為。 |
| 關閉 (填滿點字顯示器，會拆開字元) | 中日韓文字會填滿到顯示器的邊緣，即使會拆開字元。與 NVDA 相同，字元被拆開時會在該列結尾顯示接續符號 (7-8 點)，除非 NVDA 的文字換行設為「關閉」。 |
| 在字元邊界 | 任兩個中日韓字元之間都可以換行。無法完整放進該列的字元會移到下一列，因此最多只會留下幾方空白。 |
| 於下一個視窗重複被拆開的字元 (GMouse 模式) | 使用顯示器的所有點字方。當一個字元在顯示器邊緣被拆開時，捲動到下一個視窗會從該字元的第一方重新開始，因此下一個視窗會完整顯示這個字元。 |

使用後三個選項時，若 NVDA 的文字換行設為「在字詞邊界」或「在字詞或音節邊界」，中日韓字元與其他文字之間的邊界也會被視為空格。
例如中文點字與英文 (UEB) 點字混合時，緊接在中文後面的英文單字會整個移到下一列，而不是在可能很遠的上一個空格處換行。

往回捲動時也使用相同的規則，因此視窗不會從中日韓字元的中間開始 (「關閉」除外)。

### 在中文字、拉丁字母與數字之間插入空格

勾選這個選項時，會在點字轉譯前，於字元類型改變的地方插入空格，例如：

* 使用NVDA閱讀 會顯示為 使用 NVDA 閱讀
* 版本2026.3已發布 會顯示為 版本 2026.3 已發布

連續的中文字不會改變：不會進行斷詞，因此 這是一個測試 仍為 這是一個測試。
這與 NVDA 的「使用中文斷詞」設定無關。
已經有空格的地方不會再加入空格，標點符號也不會被分開。

只有在點字輸出表為中文點字表時才會套用。
插入的空格只影響點字，不會改變文字本身，游標定位也照常運作。
在插入的空格上按游標定位鍵，會將游標移到空格後面的字元。

在「插入空格的位置」清單中，選擇要插入空格的邊界：

* 中文字與拉丁字母之間 (預設勾選)
* 中文字與數字之間 (預設勾選)
* 拉丁字母與數字之間 (預設不勾選)

這個選項預設為關閉。

## 命令

以下命令沒有指定按鍵，
可在 NVDA 輸入手勢對話框的「點字」類別中指定。

* 循環切換中日韓字元的點字文字換行模式。
* 切換是否在點字中於中文字、拉丁字母與數字之間插入空格。
